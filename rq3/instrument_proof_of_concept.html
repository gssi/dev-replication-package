Questionnaire instructions

Think of a software system you know well.

Read the instructions carefully before answering. You will make hypothetical implementation choices in a consistent application context.

You will be presented with a series of software implementation scenarios. Each scenario describes a situation in which more than one implementation choice is possible. You will be asked to indicate how likely you would be to choose the implementation described in each scenario.

Before answering, think of a software system or application context that you know well, preferably one that you have worked on directly. You do not need to report or describe the system you selected. Keep the same system in mind throughout the questionnaire and evaluate each scenario in relation to that context.

For each scenario, assume that the functional and non-functional requirements do not prescribe a specific choice, that no legal or organizational rule requires one of the alternatives, and that either implementation would satisfy the intended functionality. Unless otherwise stated, assume that the difference in implementation effort is not substantial.

Imagine that you are responsible for making the implementation decision. If a scenario does not directly occur in the system you selected, consider how you would make an analogous implementation decision in that context.

There are no correct or incorrect answers. We are interested in the implementation you would personally be more likely to choose under the conditions described.

When faced with the following implementation scenarios, how likely would you be to make the described choice?

Ethical profile

Scale: 1 (lower alignment) to 5 (higher alignment). Missing aspect scores are omitted, not treated as zero.

Scores by aspect

How the scores are calculated: Very unlikely = 1, unlikely = 2, neutral = 3, likely = 4, and very likely = 5 for positive-keyed items. Reverse-keyed items use the opposite scoring direction. “Not enough information to answer” does not receive a score and is excluded from the mean.

Interpretation: This is a descriptive profile of self-reported preferences within the presented scenarios, not a judgment of a developer's ethical character. An aspect with no scored items has no average.
